
# RouteRanker – Module 3: Exploratory Data Analysis (EDA)

## Project Overview
RouteRanker analyzes public transit GTFS datasets from five Indian cities.

## Cities Covered
1. Bangalore
2. Delhi
3. Hyderabad
4. Mumbai
5. Pune

## EDA Activities
- City-wise route analysis
- Scheduled trip distribution
- Hourly trip pattern analysis
- Time-period analysis
- Route-wise hourly comparison
- Top 10 busiest routes per city
- Top 10 stops by scheduled arrivals
- Headway analysis
- Correlation analysis
- Geographic stop mapping

## Output Files
The processed CSV files are stored in:
`data/processed/module3/`

Visualizations are stored in:
`visualizations/`

The final report is stored in:
`reports/module3/Module3_EDA_Report.txt`

## Important Note
The analysis uses scheduled GTFS data. Scheduled trips and arrivals
do not directly represent actual passenger ridership or vehicle usage.

## Conclusion
Module 3 provides exploratory insights into route structures,
scheduled service frequency, stop distribution and timing patterns.
These findings support the next stages of the RouteRanker project.
