# RouteRanker
## AI-Powered Public Transit Route Analysis and Optimization

RouteRanker analyzes public transportation routes and schedules using GTFS data, Python, machine learning, and Streamlit.

## Study Cities
- Ahmedabad
- Chennai
- Hyderabad
- Mumbai
- Pune

## Project Objectives
- Process and validate GTFS datasets.
- Analyze public transit routes and schedules.
- Generate route-level features.
- Identify route patterns using clustering.
- Classify route categories using machine learning.
- Explore hypothetical schedule optimization scenarios.
- Present results through an interactive dashboard.

## Seven Modules
1. Module 1: GTFS conversion, preprocessing, and validation.
2. Module 2: Route-level feature engineering.
3. Module 3: Route data analysis and indicator generation.
4. Module 4: Data cleaning and preprocessing.
5. Module 5: K-Means, DBSCAN, Random Forest, and XGBoost.
6. Module 6: Model inference, route analysis, and hypothetical optimization.
7. Module 7: Interactive Streamlit dashboard and documentation.

## Installation

Run these commands from the project folder:

1. `py -m venv .venv`
2. `.\.venv\Scripts\Activate.ps1`
3. `py -m pip install -r requirements.txt`
4. `py -m streamlit run dashboard/app.py`

Open the local URL displayed in the terminal.

The dashboard requires the processed datasets and model files generated by previous modules.

## Data Handling
The project uses GTFS route, trip, stop, and stop-time information. Raw datasets are maintained locally and are not included in Git because of their size. Obtain the original datasets from their providers.

## Important Limitations
- GTFS schedules represent planned service, not actual passenger counts.
- The project does not measure actual passenger occupancy or overcrowding.
- Clustering does not automatically identify inefficient routes.
- DBSCAN noise points are not necessarily inefficient.
- Classification evaluation is based on Chennai data.
- Straight-line distance is not actual road distance.
- Optimization scenarios are hypothetical, not validated real-world recommendations.
- Reducing scheduled trips alone does not prove improved service quality.
